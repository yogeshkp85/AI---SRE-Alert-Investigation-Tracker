THE 5-STEP PROCESS (Quick Reference)
================================================================================

Step 1: Clone
   git clone https://github.com/yogeshkp85/AI---SRE-Alert-Investigation-Tracker.git
   cd AI---SRE-Alert-Investigation-Tracker

Step 2: Create Virtual Environment
   Windows: python -m venv venv && venv\Scripts\activate
   macOS/Linux: python3 -m venv venv && source venv/bin/activate

Step 3: Install Dependencies
   pip install flask openpyxl

Step 4: Run Application
   python app.py

Step 5: Open in Browser
   Form: http://localhost:5000/form.html
   Dashboard: http://localhost:5000/dashboard.html
   Admin: http://localhost:5000/admin.html (PIN: 9999)

Total Time: ~15-20 minutes

COMMON ISSUES & SOLUTIONS
================================================================================

"python not found"
   → Install Python from https://www.python.org/downloads/
   → Check "Add Python to PATH" during installation

"No module named 'flask'"
   → Activate venv: venv\Scripts\activate (Windows)
   → Or: source venv/bin/activate (macOS/Linux)
   → Run: pip install flask openpyxl

"Port 5000 already in use"
   → Close other applications using port 5000
   → Or change port in app.py

"Cannot find incident-tracker.xlsx"
   → Ensure you're in project root directory
   → Run: ls (macOS/Linux) or dir (Windows)

"Connection refused" at localhost:5000
   → Flask server not running
   → Run: python app.py

"git: command not found"
   → Install Git from https://git-scm.com/download

For more troubleshooting, see the detailed guides above.
